If the game crash try Dezooming the terminal

controls: 
ZQSD: movements
space: select
²: deselect
p: erase (used in the parameters)

description of the parameters:
- lives: number of errors allowed before game over
- jump: number of digit skip each time
- start: starting digit of pi in the sequence
- limit: at wich digit the games stops
- modes: select the available modes 

description of the modes:
- classic: just writte down the pi sequence normaly
- trainning: a mode where you can't game over and the next 2 digits are written on the right (allow you to learn the sequence)
- geoguesse: gives you a sequence of 6 digits and you must figure out the next digit in the sequence (the sequence of digits will be one within the range of the start and limmit param (limit=99999 if left empty))
